# Mini-project 2: URL Explorer Tĩnh

Dự án trang web tĩnh cung cấp các kiến thức cơ bản về cơ sở hạ tầng web bao gồm **Domain (Tên miền)**, **Hosting (Lưu trữ)**, và cấu trúc chi tiết của một **URL**.

## 🚀 Tính năng nổi bật
- Giao diện thiết kế theo chuẩn Responsive (Tự động co giãn trên Mobile & PC).
- Sử dụng mô hình Flexbox & CSS Grid cho Layout sạch sẽ, khoa học.
- Hệ thống tương tác JavaScript: Click chọn trực tiếp vào từng thành phần của URL thực tế để xem phân tích ý nghĩa chi tiết.

## 📂 Cấu trúc thư mục mã nguồn
- `index.html`: Cấu trúc nội dung chính của website.
- `css/style.css`: Quản lý style giao diện, màu sắc phân loại cấu trúc.
- `js/script.js`: Xử lý logic tương tác click-to-explain.
