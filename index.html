Khám Phá Hạ Tầng Mạng Quốc Tế

Bản đồ tương tác toàn diện giúp phân tích chuyên sâu về Domain, Hosting, URL và nguyên lý vận hành của các gói tin trên môi trường Internet toàn cầu.

Bắt Đầu Trực Quan Hóa ➔

1. Ba Trụ Cột Của Một Website

Hiểu rõ các thành phần bắt buộc phải có để một trang web có thể hiển thị tới người dùng cuối.

🏠

Domain Name (Tên miền)

Là chuỗi ký tự thuộc ngôn ngữ tự nhiên được ánh xạ thay thế cho các địa chỉ IP số (Internet Protocol) phức tạp của máy chủ web, giúp con người dễ dàng ghi nhớ.

  • Cấp 1 (TLD): .com, .vn, .org
  • Cấp 2 (SLD): google, github
  • Mục đích: Định danh thương hiệu trên không gian số.
📦

Web Hosting (Lưu trữ)

Là không gian đĩa cứng (ổ lưu trữ SSD/NVMe) được thuê trên một Máy chủ (Server) kết nối Internet tốc độ cao 24/7, chứa các file mã nguồn của website.

  • Thành phần: Source code, Database, Media assets.
  • Yêu cầu: Băng thông lớn, Uptime 99.9%, bảo mật tốt.
  • Hạ tầng mẫu: GitHub Pages (Hosting tĩnh chuyên biệt).
🔗

URL (Đường dẫn đồng nhất)

Là viết tắt của Uniform Resource Locator, một chuỗi ký tự tiêu chuẩn hóa dùng để định vị chính xác vị trí của bất kỳ tài nguyên nào trên Internet.

  • Độ phủ: Trỏ đến trang HTML, ảnh, video, hoặc API.
  • Cấu trúc cơ bản: Giao thức + Tên miền + Đường dẫn file.
  • Đặc tính: Duy nhất trên toàn mạng Internet quốc tế.

2. Bảng Phân Tích Kỹ Thuật Hạ Tầng Web

Bảng số liệu và tính năng giúp hệ thống hóa kiến thức quản trị mạng máy tính cơ bản.

Thành phần kĩ thuật Bản chất vật lý / Logic Ví dụ thực tế Cách thức tương tác hệ thống
Giao thức (Protocol) Tập hợp quy tắc mã hóa và truyền tải dữ liệu an toàn qua mạng. HTTP, HTTPS, FTP Trình duyệt tự động phân tích để thiết lập kênh kết nối bảo mật SSL.
Hệ thống DNS Hệ thống phân giải tên miền (Giống danh bạ điện thoại toàn cầu). DNS của Google: 8.8.8.8 Chuyển đổi tên miền chữ viết (ví dụ: `github.com`) thành số IP (`140.82.113.3`).
Web Server Phần cứng máy chủ vật lý chạy phần mềm phân phối mã nguồn. Nginx, Apache, GitHub Server Nhận request từ Client, xử lý tệp tin và trả mã phản hồi (Response: 200, 404).

3. Bộ Trực Quan Hóa Cấu Trúc URL Tương Tác

Nhấp chuột trực tiếp vào từng khối phân đoạn màu sắc của URL để xem định nghĩa kỹ thuật từ hệ thống biên dịch.

Mẫu URL 01: Chuỗi truy vấn Tìm kiếm thương mại điện tử (Dynamic URL)

https://shopee.vn/search?keyword=laptop

💡 Vui lòng bấm vào một thành phần bất kỳ của chuỗi URL phía trên để xem phân tích cấu trúc chi tiết...

🛡️ Giao thức (Protocol) - https://

Hypertext Transfer Protocol Secure. Giao thức truyền tải siêu văn bản an toàn, bắt buộc mọi dữ liệu truyền giữa trình duyệt của bạn và Shopee phải được mã hóa để tránh bị tin tặc đánh cắp thông tin.

🌐 Tên miền chính (Host / Domain) - shopee.vn

Đại diện cho định danh thương hiệu của sàn thương mại điện tử Shopee tại thị trường Việt Nam. Nó trỏ về cụm địa chỉ IP của máy chủ lưu trữ Shopee thông qua hệ thống DNS.

📂 Đường dẫn thư mục (Path) - /search

Chỉ định đường dẫn tương đối dẫn tới thư mục hoặc router con chịu trách nhiệm kích hoạt giao diện và mã lệnh tìm kiếm sản phẩm trên hệ thống phần mềm của Server.

⚙️ Tham số truy vấn (Query String) - ?keyword=laptop

Chuỗi gửi dữ liệu biến động lên máy chủ. Bắt đầu bằng dấu ? và chứa cặp Khóa=Giá trị. Ở đây khóa keyword mang giá trị là dữ liệu người dùng gõ vào: laptop.

Mẫu URL 02: Đường dẫn phân tầng chạy trên Hosting GitHub Pages (Static URL)

https://trungnghia.github.io/mini-project-2/index.html

💡 Vui lòng bấm vào một thành phần bất kỳ của chuỗi URL phía trên để xem phân tích cấu trúc chi tiết...

🛡️ Giao thức (Protocol) - https://

Giao thức bảo mật tiêu chuẩn giúp mã hóa trang web tĩnh cá nhân, đảm bảo trang web của bạn đạt điểm uy tín cao trên các trình duyệt hiện đại như Chrome, Cốc Cốc.

🏢 Tên miền phụ (Subdomain) - trungnghia.

Là một nhánh con được tách lập riêng từ tên miền mẹ. Ở đây hệ thống GitHub tự động cấp phát tên miền phụ dựa trên tên tài khoản (Username) của người dùng nhằm định danh phân vùng lưu trữ cá nhân.

🌐 Tên miền gốc dịch vụ (Root Domain) - github.io

Tên miền hệ thống máy chủ cung cấp nền tảng hosting tĩnh (GitHub Pages) của tập đoàn GitHub, quản trị việc phân phối các sản phẩm mã nguồn mở toàn cầu.

📄 Đường dẫn tệp tin cụ thể (Path / Resource File) - /mini-project-2/index.html

Chỉ rõ cấu trúc thư mục lưu trữ: Vào thư mục dự án mang tên mini-project-2 và gọi chính xác file tài nguyên cấu trúc giao diện index.html để hiển thị lên màn hình.
